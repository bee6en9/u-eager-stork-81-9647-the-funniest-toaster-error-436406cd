A deterministic Node program (no external dependencies) that writes one line
— the funniest error message a kitchen toaster would show its owner — to
`/output/entry.txt`.

Run it with:

```sh
node main.ts
```

Entry text:

> ERROR: Crumb tray full. I am 94% crumbs now. Send help, or a vacuum.
